# v2.2.0

- 请求超时从 180 秒延长到 600 秒。部分渠道生图要 3–10 分钟，旧版到 180 秒就断开，图已生成扣费却拿不到。
- 失败按阶段报错，不再全部报成"状态未知"：
  - `request was not sent`：连不上 88API，请求没有发出、没有扣费，自动重试。
  - `stage: submit`：提交后状态未知，可能已扣费，不自动重发。
  - `stage: read-result`：已收到响应、已扣费，读取结果时连接中断。
  - `stage: download`：已扣费，结果图下载失败。
- 结果是链接时，下载前先把链接保存到输出目录的 `*.pending-download.json`，免费重试 3 次；仍失败时保留文件，用 `--retry-download <文件>` 只下载、不发新的付费请求。
- 新增 `--self-test-download`，并纳入 `--self-test`。
- 88API 服务器 2026-10-22 起默认直接返回图片数据，通常不会再走到下载这一步；下载保护用于兼容仍返回链接的情况。
