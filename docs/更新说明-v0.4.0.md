# 更新说明 v0.4.0

`0.4.0` 为 `gpt-image-2` 增加 Images API 原生流式预览、智能提示词和更严格的费用安全策略。

## Image2 接口

- 文生图只使用 `/v1/images/generations`。
- 图生图和多参考图只使用 `/v1/images/edits`。
- 模型固定为 `gpt-image-2`，不需要 GPT‑5.5 或其他文本模型权限。
- `--transport auto` 作为兼容参数保留，并统一解析为 Images API；Responses 路由已禁用。

## 流式预览

- 单个文生图任务可通过 `--preview` 使用 Images API 原生 SSE 保存 partial-image 预览。
- 预览默认关闭，批量任务不启用。
- partial image 可能增加图像输出用量，实际费用以 88API 控制台为准。

## 提示词与任务编排

- Codex 当前会话负责理解需求、参考图角色映射和提示词整理。
- 用户要求原文直传时保留原始提示词。
- 明确要求迭代时，可执行一次“生成、检查、编辑”；每次编辑均为独立请求。
- 默认只生成用户要求的数量，不自动追加未披露的变体。

## 费用与稳定性

- 已受理、SSE 中断、超时或状态未知的请求标记为 `[NO-RETRY]`。
- `[NO-RETRY]` 请求不会自动换 worker、切换接口或重新提交。
- 批量任务继续使用 worker 冷却、断点续跑、自动补洞和结果报告。
- 上游原始像素不精确时，继续使用跨平台本地尺寸处理。
