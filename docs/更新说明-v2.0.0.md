# 更新说明 v2.0.0

`2.0.0` 将插件收敛为标准 Image2 与 Image2 4K 两个模型。这是移除旧能力参数的破坏性更新。

## 模型

- 保留 `gpt-image-2`，固定使用 2K 尺寸矩阵。
- 保留 `gpt-image-2-4k`，固定使用 4K 尺寸矩阵。
- 已移除模型不再出现在配置、请求、Skill、插件清单和当前文档中。
- 旧配置如果保存了不再支持的模型，加载时自动迁移为默认 `gpt-image-2`。

## 已移除能力

- 透明背景和本地键色转 Alpha。
- 精确自定义像素尺寸。
- 非支持比例的自动模型路由。
- 与上述能力关联的命令参数、自测、日志字段和 workflow 元数据。

旧参数现在作为未知参数在本地拒绝，不会调用付费 API。

## 尺寸安全

- 只接受 `1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`16:9`、`9:16`、`2:1`、`1:2`、`7:4`、`4:7`。
- 每个最终预设在请求前检查 16 像素对齐、最长边、最大宽高比和总像素范围。
- 4K `4:3` 调整为 `3264x2448`。
- 4K `3:4` 调整为 `2448x3264`。
- 不支持的比例会在付费请求前明确失败，不再自动转换。

## 保留能力

- OpenAI Images API 文生图与图片编辑。
- 多参考图 multipart `image[]` 上传。
- 单张文生图可选 SSE partial-image 预览。
- 单 Key 并发请求槽、批量、workflow、断点续跑和费用安全策略。
- `--dry-run`、配置脱敏和统一自测。
