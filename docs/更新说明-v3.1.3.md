# v3.1.3

和视频插件共用 Key。

- **复用 88API-Video-Studio 的 Key**：本插件还没有自己的 Key 时，会直接使用视频插件 [88API-Video-Studio](https://github.com/blackdm666/88API-Video-Studio) 保存的 API Key（`~/.88api/video-studio.json`，视频插件 0.12.0 之前是 `~/.seedance-studio/config.json`），不用再配一次。这个 Key 只读取、不复制，视频插件里换了 Key 这边也跟着用新的；`--get-config` 的「Key来源」会写明来自哪个文件。想给生图插件单独配 Key，照常发给 Agent 让它 `--set-key` 即可，之后优先用自己的。
- 视频插件 0.12.0 起也会复用本插件的 Key，所以两个插件装哪个先配都行。
- 功能没有其它变化。

升级后：Codex 新建任务，Claude Code / ZCode / Trae 新开对话，以重新加载技能。DeepSeek Harness 在插件设置里卸载后重新添加，再完全退出并重新打开 DSH。
