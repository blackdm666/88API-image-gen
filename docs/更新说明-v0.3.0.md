# 更新说明 v0.3.0

`0.3.0` 增加 `gpt-image-2` Images API 传输，为后续混合传输提供低内存批量链路。

## API 支持

- 文生图：`POST https://88api.ai/v1/images/generations`
- 图生图：`POST https://88api.ai/v1/images/edits`
- 模型：`gpt-image-2`
- 文生图使用 JSON 请求。
- 图生图和多参考图使用 multipart `image[]` 上传。
- 返回结果支持 `data[].b64_json` 和 `data[].url`。

## 资源优化

- 保留单图、多参考图、批量编辑、worker 池、断点续跑和补洞能力。
- 移除参考图的 base64 Data URL 常驻副本。
- 批量工作流日志不保存完整图片 base64 或签名 URL，只记录状态、用量和数据长度。
