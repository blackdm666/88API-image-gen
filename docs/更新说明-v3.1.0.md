# v3.1.0

DeepSeek Harness 可以直接安装本插件了。

- **DeepSeek Harness 一键安装**：打开「添加插件」，填入 `github:blackdm666/88API-image-gen`，点「安装」，然后新开对话即可使用，不用再手动复制技能文件夹。装的是和 Claude Code、Codex、ZCode 同一份技能，功能完全一样。
- **原生插件 dsh-plugin-88api-image 停止更新**：它只有四个旧模型（含已下线的 `gpt-image-2-4k`）。装过的请先在插件设置里卸载，再安装本插件。
- **已经把技能文件夹复制到 `~/.dsh/skills/` 的用户**：可以继续这样用；如果又装了插件，DSH 用插件装的那份，建议删掉复制的文件夹，免得以后升级时两份版本不一致。
- Claude Code、Codex、ZCode 的安装和使用没有变化。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。DeepSeek Harness 暂不支持插件自动更新，以后升级要先卸载再重新添加。
