# v2.3.0

不再只限 Codex：同一个插件可以在 Claude Code、ZCode、DeepSeek Harness 以及能运行本机 Node.js 命令的其它 Agent 客户端中使用。

- **Claude Code / ZCode 插件**：新增 `plugins/88api-image-gen/.claude-plugin/plugin.json` 和仓库根目录 `.claude-plugin/marketplace.json`。Claude Code 用 `/plugin marketplace add blackdm666/88API-image-gen` 安装；ZCode 兼容同一格式，在 设置 → Plugins → Add marketplace 中添加本仓库。
- **技能文件夹自带脚本**：`generate.mjs` 从 `plugins/88api-image-gen/scripts/` 移到 `plugins/88api-image-gen/skills/88api-image-gen/scripts/`。整个技能文件夹可以直接复制到其它客户端的技能目录（如 `~/.agents/skills/`、`~/.dsh/skills/`、`~/.cline/skills/`）。
- **Key 改存客户端通用位置**：`~/.88api/image-gen.json`。旧版保存在 `~/.codex/88api-image-gen-config.json` 的 Key 第一次使用时自动复制过来，旧文件保留，并在保存时同步更新，未升级的旧版插件仍可使用。
  - 新增环境变量 `API88_KEY`：优先于配置文件，不写盘，适合不想把 Key 发进对话的用户。
  - 新增环境变量 `API88_CONFIG_DIR`：改配置目录（设置后不再读取、同步旧路径）。
  - `--get-config` 新增「Key来源」「旧版配置同步」两项。
- **提交记录与 `--job-status`**：每次付费运行在 `~/.88api/image-gen-jobs/` 写一份记录，每个请求发出前就先记下。客户端因超时把命令结束后，运行 `--job-status <任务号>`（不带参数列出最近几次）即可查清每个请求是已保存、未发出、被 88API 拒绝、仍在运行，还是 `[NO-AUTO-RETRY]` 状态未知 / 被中断（可能已扣费）。该命令不发请求、不收费。
- **`--json`**：付费运行结束时多输出一行机器可读结果，结构与 `--job-status` 相同。
- **技能说明**：去掉 Codex 专属表述；新增「长任务与客户端命令超时」一节，要求 Claude Code 把付费命令放到后台运行，任何客户端中断后先查 `--job-status`、不得盲目重发。Codex Auto 模式审批的说明保持不变。
- **修复**：Windows + Node 24 下，付费运行结束时进程会因 libuv 断言（`UV_HANDLE_CLOSING`）崩溃，退出码变成 127，Agent 可能把成功误判为失败。现在改为设置退出码后自然退出。
- `--self-test` 新增 `config-job` 用例：旧配置迁移与同步、环境变量 Key、提交记录各状态、进程被中断的识别。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。
