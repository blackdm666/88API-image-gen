# v3.0.3

来自 v3.0.2 的全模型实测和 DeepSeek Harness 实测，修三个问题。

- **GPT Image 改图不再被裁成方形**：不传 `--aspect` 时，GPT Image 模型按第一张本地参考图选最接近的支持比例（例如 1536×1024 的参考图出 3:2），并打印提示；Gemini、Grok 本来就跟随参考图，行为不变。显式传 `--aspect` 时以传入的为准。
- **沙箱客户端里默认目录不可写时自动改用工作目录**：DeepSeek Harness 等只允许写工作目录的客户端里，`~/Pictures/88api-image-gen` 或 `~/.88api/image-gen-jobs` 写不进去时，改存到当前工作目录下的 `88api-images` 和 `.88api-image-gen-jobs`，并打印实际位置；`--job-status` 两处都会查。显式传了 `--output-dir` 时不改动，照常报错。读取配置时顺带的迁移 / 规范化回写失败，也不再让这次运行丢掉已读到的 Key。
- **技能说明禁止直接读 Key 配置文件**：Key 只能用 `--get-config` 检查，不得打开、解析、复制配置文件，也不得自己把 Key 放进命令行或环境变量去绕过沙箱。沙箱里写不进去时不要用 `API88_CONFIG_DIR`、`API88_KEY` 或申请完全访问来绕开。
- `--self-test` 新增 `sandbox` 用例：目录回退、其它错误照常报出、参考图比例推断。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。
