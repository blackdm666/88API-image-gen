# 88API-image-gen v1.0.0

`1.0.0` 是三模型、统一配置与无付费验证能力的首个正式版本。

## 新增模型

- 保留 `gpt-image-2` 为出厂默认模型，使用现有 2K 尺寸矩阵。
- 新增 `gpt-image-2-4k`，使用 4K 尺寸矩阵。
- 新增 `gpt-image-2-adobe`，使用 4K 尺寸矩阵，并提供透明 PNG、非原生比例和自定义尺寸能力。
- 三款模型统一通过 88API OpenAI Images API，覆盖文生图、编辑、多参考图、SSE 预览、多图、批量和 workflow。
- 透明背景、显式 `--size`、21:9 等非原生比例会在付费请求前自动路由 Adobe，并记录切换原因；失败后不做跨模型回退。
- 透明任务采用纯绿/纯洋红键色源图并在本地生成真实 PNG Alpha 通道；若返回结果既无 Alpha 又无可用键色，将以 `[NO-RETRY]` 失败，不会保存伪透明成品。

## CLI 与配置

- 新增 `--model`、`--set-model`、`--list-models`、`--config-path`、统一 `--self-test`。
- 优先级固定为：单次 `--model` > 配置文件模型 > `gpt-image-2`。
- 配置改为单 Key 入口：新安装只需一个 `auto` 分组 Key，并发请求由上游自动分配。
- 旧多 worker 配置读取时保留，运行只使用第一个启用 Key；执行 `--set-key` 后收敛为单 Key，同时保留模型与已有模式设置。
- 配置写入改为同目录临时文件加原子替换。
- 旧 `--quality` 保持兼容，但分辨率档位由模型决定。
- `--size WIDTHxHEIGHT` 重新启用为 Adobe 专属能力；新增 `--background` 和 `--transparent`。

## 无付费验证与费用安全

- `--dry-run` 已覆盖普通生成、编辑、多参考图、多图、批量和 workflow。
- dry-run 不要求 Key、不调用付费 API、不输出参考图 Base64，只显示端点、模型、档位、尺寸、任务数与脱敏请求。
- 统一 `--self-test` 聚合单 Key 并发槽、兼容调度、Images JSON/FormData、SSE、透明 PNG 像素转换、workflow、模型配置迁移、尺寸矩阵和脱敏检查。
- SSE 解析兼容最终图片以 Base64 或 URL 事件返回，两种响应都由模拟测试覆盖。
- 保留原有细分自测参数。
- 已受理或状态未知的请求继续标记 `[NO-RETRY]`，不会自动重发。

## 技能与文档

- 精简 `SKILL.md`，加入 4K/Adobe 路由、插件根目录解析、全模式示例和费用安全规则。
- 新增 `agents/openai.yaml`，改善 Codex UI 与 `$88api-image-gen` 默认调用体验。
- 参照 88api-Nano-Banana 的结构重写 README，补齐模型选择、安装升级、单 Key 配置、自动安装提示词、`@` 调用、API 协议、安全验证和排错章节。
- Key 教程复用 88api-Nano-Banana 当前版本的创建与复制截图，展示 `auto` 自动分组。
- 不对 Adobe 模型作版权、许可或商用安全等未经验证的承诺。

## 尺寸验证

`16:9` 解析结果：

- `gpt-image-2` → `2048x1152`
- `gpt-image-2-4k` → `3840x2160`
- `gpt-image-2-adobe` → `3840x2160`

Image2 保留 11 个原生比例；其他合法比例自动路由 Adobe。`21:9` 默认解析为 `3808x1632`，原先禁用的 `5:4`、`4:5`、`3:1`、`1:3` 也改由 Adobe 处理。
