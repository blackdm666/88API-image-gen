# 更新说明 v0.2.0

`0.2.0` 完成了插件品牌、接口和首次使用流程的整体升级。

## 主要变化

- 插件标识改为 `88api-image-gen`，Marketplace 改为 `88api-plugins`。
- Responses API 地址改为 `https://88api.ai/v1/responses`。
- 新增 88API 生图分组 Key 的图文创建和配置教程。
- 默认建议单 Key、单 worker 和 `--concurrency 1`；批量工作流必须先 `--dry-run`。
- 明确提醒低配置电脑不要运行批量生图，并说明本地崩溃不等于云端请求取消，已受理请求仍可能计费。
- 精确尺寸后处理支持 Windows、macOS 和 Linux/Unix。
- 加强本地 Key 文件权限、旧配置迁移和损坏配置提示。
- 修复 Skill 文档乱码并统一安装、调用和排错说明。

## 安装

```bash
codex plugin marketplace add blackdm666/88API-image-gen
codex plugin add 88api-image-gen@88api-plugins
```

安装并配置 Key 后，直接在 Codex 对话中提出生图需求即可，无需启动常驻服务。
