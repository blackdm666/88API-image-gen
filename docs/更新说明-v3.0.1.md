# v3.0.1

修复两个显示问题，补全技能说明。来自 v3.0.0 装进 Claude Code 后的实测。

- **修复**：单张文生图结束时打印 `Prompt: "undefined"`（v2.3.0 起就有）。现在显示实际提示词。
- **修复**：进度行原来固定打印 `Transport: images`，Gemini 走的其实是 Chat Completions，容易误以为走错了接口。现在改为 `Route:` 行，显示这次实际调用的协议和端点，例如 `Route: Chat Completions https://88api.ai/v1/chat/completions` 或 `Route: Images API https://88api.ai/v1/images/edits (json)`。
- **技能说明补全**：
  - 写明图片默认保存到 `~/Pictures/88api-image-gen`，可用 `--output-dir` 改。
  - 写明不传 `--resolution` 时的取值顺序（快速 / 批量模式保存的分辨率，否则清单默认值，目前都是 1K），以及同档位同比例在不同模型上像素不同（1K 16:9：GPT Image、Grok 是 1280×720，Gemini 是 1376×768），付费前可用 `--dry-run` / `--resolve-size` 查看。
  - Grok 选模型：生成和编辑默认都用 `grok-imagine-image`；要更高画质用 `grok-imagine-image-quality`，要最讲究的排版用 `grok-imagine-image-2.0`；`grok-imagine-edit` 和 quality 版是同一个模型，不需要专门选。编辑示例改成 `grok-imagine-image`。
  - 「更贵的模型先问」改成明确的清单：清单里只有计费方式没有单价，哪些选择要先问用户（Gemini Pro、az 高质量档或 2K/4K、Midjourney）；价格让用户看 https://88api.ai/pricing，不凭记忆报价。
  - 完成汇报去掉了输出里并不存在的「请求槽位」。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。
