# v3.0.0

一个插件调用 88API 全部生图模型，模型能力不再写死在插件里。

- **按模型清单出图**：插件读取 88API 文档站发布的模型清单 `https://88api.ai/helper/image-models.json`（由各生图规范页生成），本机缓存在 `~/.88api/image-models.json`，每天更新一次，并内置一份快照 `scripts/image-models.snapshot.json` 作为离线兜底。清单决定每个模型：
  - 走哪个接口：GPT Image、Grok、Seedream、Midjourney 用 Images API，Gemini 用 Chat Completions；
  - 尺寸怎么传：GPT Image 填像素，Grok 填 `aspect_ratio` + `resolution`，Gemini 填 `extra_body.google.image_config`，Seedream 填档位，Midjourney 在提示词里加 `--ar`；
  - 参考图怎么传、最多几张：multipart、JSON 的 data URI / 公网 URL，或 Chat Completions 的图片内容；
  - 允许的比例、分辨率、质量档位、背景和输出格式。
  所有参数在付费请求前按清单校验，不支持时报错并列出可用取值。
- **新增模型**：`az-gpt-image-2`、`az-gpt-image-2.5-flare`、`az-gpt-image-2.5-sunburst`，Gemini 三个（`gemini-3.1-flash-image`、`gemini-nano-banana-2.1`、`gemini-3-pro-image`），Grok Imagine 四个，`doubao-seedream-5-0-pro`，Midjourney V8.2 三个。88API 以后上新模型或调整参数，只要文档站更新，插件不用升级。
- **88API-Nano-Banana 停止更新**：Gemini 生图并入本插件，解析逻辑来自 Nano（直连 HTTPS、不压缩、128 MB 响应上限、不开流式）。只配过 Nano 的用户，Key 和默认模型会从 `~/.88api/nano-banana.json` 自动迁移。
- **新参数**：
  - `--resolution 1K|2K|4K`：替代原来的「4K 模型」。`gpt-image-2-4k` 已下线，旧命令和旧配置里的 `gpt-image-2-4k` 自动转成 `gpt-image-2` + 4K；旧的 `--quality 2K/4K` 也按分辨率处理。
  - `--quality`：现在是模型的质量档位（如 `low|medium|high`，`az-gpt-image-2.5-*` 另有 `xhigh|max`）。
  - `--background transparent|opaque|auto`、`--output-format png|webp|jpeg`：只在清单列出的模型上可用（目前是 `az-gpt-image-*`）。
  - `--refresh-models`：立即重新拉取模型清单。
  - `--image` 也可以填公网图片 URL，用于支持 URL 参考图的模型（Grok、Seedream、Gemini、az）。
- **`--list-models` 联网按 Key 标出可用模型**：调用免费的 `/v1/models`，每个清单模型带 `available`；Key 能用但清单还没收录的生图模型列在 `undocumented`。点名清单没有、但 Key 能用的模型时，插件只发提示词和参考图试用（不发尺寸、质量等参数）。
- **尺寸预设更新**：GPT Image 的像素表改用文档站实测的 1K/2K/4K 预设（例如 2K 16:9 由 2048×1152 改为 2560×1440），比例改为 1:1、3:2、2:3、4:3、3:4、16:9、9:16、21:9、2:1、1:2（去掉 7:4、4:7）。没保存过快速模式的用户，GPT Image 默认分辨率是 1K；要 2K 请传 `--resolution 2K` 或用 `--set-quick-mode --resolution 2K` 保存。
- **结果保存**：按图片真实格式命名（Grok 1K 和多数 Gemini 结果是 JPEG），能读出 JPEG / WebP 的尺寸；Midjourney 一次返回的 4 张都会保存并列出。本地裁切 / 缩放只对按像素出图的 GPT Image 模型生效。
- **安全**：清单只能指向 88api.ai 上固定的几个接口路径，格式不对或被篡改时插件拒用并改用缓存或内置快照；`--dry-run` 不联网，只用缓存或快照。
- `--self-test` 更新：覆盖清单里每个模型的请求构造、像素预设校验、恶意清单拦截、参考图上限、Gemini 响应解析和旧配置迁移。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。
