# 项目说明

`88API-image-gen` 是来源于 [88api.ai Token 聚合站](https://88api.ai/) 的 Codex 图像生成插件。当前版本为 `1.0.0`，通过 88API OpenAI Images API 支持：

- `gpt-image-2`：默认 2K。
- `gpt-image-2-4k`：4K。
- `gpt-image-2-adobe`：Adobe 4K，并承担透明通道、非原生比例和自定义尺寸。

三款模型都覆盖文生图、图片编辑、多参考图、SSE 预览、多图、批量和 workflow。透明背景、显式 `--size` 或非原生比例会在付费请求前自动路由 Adobe，并记录请求模型、实际模型和原因；失败后仍禁止跨模型回退。

## 关键文件

- `.agents/plugins/marketplace.json`：登记 `88api-plugins` marketplace 及插件来源。
- `plugins/88api-image-gen/.codex-plugin/plugin.json`：插件版本、展示信息、图标和能力元数据。
- `plugins/88api-image-gen/scripts/generate.mjs`：单 Key 配置、模型路由、Images API 请求、SSE、图片保存、并发调度、批量和 workflow 的单一运行入口。
- `plugins/88api-image-gen/skills/88api-image-gen/SKILL.md`：告诉 Codex 何时调用插件、如何路由 4K/Adobe、如何控制费用与重试。
- `plugins/88api-image-gen/skills/88api-image-gen/agents/openai.yaml`：Codex UI 展示名称、短描述和默认提示词。
- `README.md`：面向安装者和使用者的完整中文教程。
- `VERSION.txt`：仓库发布版本；Git 标签使用带 `v` 的形式，例如 `v1.0.0`。

## 配置契约

配置文件默认位于 `~/.codex/88api-image-gen-config.json`。插件公开使用一个 `auto` 分组 Key；旧多 worker 配置读取时不会被静默删除，但运行只选择第一个启用 Key，再次执行 `--set-key` 后会收敛为单 Key。模型、快速模式和批量模式继续保留，写入采用同目录临时文件加原子替换。

基础模型优先级：单次 `--model` > 保存的 `model` > `gpt-image-2`。Adobe 专属能力路由优先于基础模型，但只影响单次请求，不改保存配置。

真实 Key 只允许保存在用户本机配置，不得出现在源码、文档、提交、Release、日志或聊天回复中。`--get-config` 只显示单个活动 Key 的脱敏摘要。一个 Key 可建立多个本地请求槽，并由 88API `auto` 分组在上游自动分配。

## API 与安全边界

- 文生图：`POST /v1/images/generations`。
- 图片编辑：`POST /v1/images/edits`，多参考图使用 multipart `image[]`。
- 不调用 `/v1/responses`。
- 透明背景请求仍发送 `background=transparent` 和 PNG 输出，同时追加纯绿/纯洋红键色提示；保存前使用 Node.js 内置 PNG 解码、键色去除与 RGBA 编码生成真实 Alpha 通道。没有检测到键色或 Alpha 时按 `[NO-RETRY]` 失败处理。
- 21:9 等非原生比例和显式自定义尺寸在请求前路由 Adobe。
- 不在失败后跨模型回退。
- 已受理或状态未知的请求使用 `[NO-RETRY]`，不得自动重发。
- `--dry-run` 不要求 Key、不调用付费 API、不输出图片 Base64。
- 透明后处理发生在本地保存阶段，不改变 OpenAI Images API 端点、认证方式或模型字段。
- Adobe 模型名称只描述上游模型线路；项目不宣称版权、许可、商业安全或其他未经验证的能力。

## 开发与发布验证

基础验证：

```powershell
node plugins/88api-image-gen/scripts/generate.mjs --self-test
node plugins/88api-image-gen/scripts/generate.mjs --resolve-size --model gpt-image-2 --aspect 16:9
node plugins/88api-image-gen/scripts/generate.mjs --resolve-size --model gpt-image-2-4k --aspect 16:9
node plugins/88api-image-gen/scripts/generate.mjs --resolve-size --model gpt-image-2-adobe --aspect 16:9
```

发布流程固定为开发分支 → draft PR → ready → squash merge → annotated tag → GitHub Release，不直接推送 `main`。
