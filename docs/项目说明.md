# 项目说明

`88API-Image-Gen` 是来源于 [88api.ai](https://88api.ai/) 的 Codex 图像生成插件。当前版本为 `2.0.1`，通过 OpenAI Images API 支持：

- `gpt-image-2`：默认 2K。
- `gpt-image-2-4k`：4K。

两款模型均覆盖文生图、图片编辑、多参考图、单任务 SSE 预览、多图、批量和 workflow。模型档位由模型名决定，不进行自动跨模型路由或失败回退。

## 配置契约

配置文件默认位于 `~/.codex/88api-image-gen-config.json`。插件公开使用一个 `auto` 分组 Key；旧多 worker 配置仍可读取，但运行只选择第一个启用 Key，再次执行 `--set-key` 后会收敛为单 Key。

模型优先级：单次 `--model` > 保存的 `model` > `gpt-image-2`。旧配置中的已移除模型会在加载时迁移为 `gpt-image-2`。

真实 Key 只允许保存在用户本机配置，不得出现在源码、文档、提交、Release、日志或聊天回复中。`--get-config` 只显示活动 Key 的脱敏摘要。

## API 与安全边界

- 文生图：`POST /v1/images/generations`。
- 图片编辑：`POST /v1/images/edits`，多参考图使用 multipart `image[]`。
- 不调用 `/v1/responses`。
- 只接受 11 个固定比例，并按 2K/4K 矩阵生成请求尺寸。
- 最终尺寸在付费请求前检查 16 像素对齐、最大边 `3840`、最大宽高比 `3:1`、总像素 `655360～8294400`。
- 不支持的比例和未知参数在本地终止，不发起付费请求。
- 已受理或状态未知的请求使用 `[NO-RETRY]`，不得自动重发。
- `--dry-run` 不要求 Key、不调用付费 API、不输出图片 Base64。

## 开发与发布验证

```powershell
node plugins/88api-image-gen/scripts/generate.mjs --self-test
node plugins/88api-image-gen/scripts/generate.mjs --resolve-size --model gpt-image-2 --aspect 16:9
node plugins/88api-image-gen/scripts/generate.mjs --resolve-size --model gpt-image-2-4k --aspect 16:9
node plugins/88api-image-gen/scripts/generate.mjs --model gpt-image-2-4k --prompt "probe" --aspect 4:3 --dry-run
```

发布流程为开发分支 → draft PR → ready → squash merge → annotated tag → GitHub Release，不直接推送 `main`。

升级后新建 Codex 任务，以重新加载技能清单。
