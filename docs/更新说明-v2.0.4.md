# v2.0.4 更新说明

本版本补充 Codex Auto 模式下的批量任务和外网审批故障说明，不改变 88API 请求端点、模型或计费方式。

## 批量调用

- 两张及以上图片必须先整理完整任务清单，再由一次插件命令调度。
- 禁止为每张图片分别启动 Node 进程，减少重复外网审批导致后续任务无法启动的情况。
- workflow 保留一次本地 `--dry-run`，确认后只执行一次正式批量命令；`dry-run` 本身不访问 88API。

## 审批错误提示

- 明确区分 Codex 外网执行授权、沙箱网络权限或审批服务 429 与 88API 的 HTTP 错误。
- 对明确在请求发出前被拦截的任务，说明其没有到达 88API、没有对应日志，也不会产生该部分费用。
- 对此前已被 88API 受理的任务单独说明，避免错误承诺整批任务均未计费。
- 向用户提供桌面端 **General（通用）→ Permissions（权限）→ Full access（完全访问）** 操作步骤，并提示完全访问会取消本地沙箱与审批边界。

## 版本

- 插件版本升级至 `2.0.4`。
